# DroidTaskFlow（开源前端）

> 面向 Android 自动化场景的可视化流程编排工具，无需编写代码即可构建、运行与共享自动化任务。

---

## 项目简介

DroidTaskFlow 是一款**可视化的 Android 自动化工具**。用户无需具备编程基础，通过在画布上拖拽功能模块并建立连线，即可完成自动化流程的编排；流程构建完成后将自动生成可执行的 Python 脚本，便于保存与复用。

该工具适用于常见的重复性手机操作自动化场景，例如自动点击、表单填写、屏幕截图、定时执行等。

---

## 核心设计理念

**节点：流程的编排容器。**
画布上的每个节点对应一段自动化流程，内部遵循统一的三段式结构：

- **INFO —— 信息提取**：采集当前场景的状态信息，如界面、截图、设备状态、全局变量等
- **LOGIC —— 逻辑分析**：对采集到的信息进行判断与计算，如图像匹配、OCR 识别、条件比较、自定义逻辑等
- **OPERATE —— 执行操作**：依据分析结果执行相应动作，如点击、滑动、亮屏/息屏、启动或关闭应用等

三个阶段依次衔接，构成一段完整的自动化流程。

**任务（卡片）：可复用的最小功能单元。**
每一项任务以「卡片」形式呈现，包含**参数配置**（用于设定功能的执行方式）与**输出端口**（用于将结果传递至后续卡片）。将卡片拖入节点的对应阶段即可完成一步流程；多张卡片依次排列，即构成一条完整的自动化流程。

**卡片化：所见即所得。**
编辑器以卡片为基本操作单元：任务面板列出全部可用卡片，拖拽至节点即可使用。参数通过表单配置，卡片之间以连线传递数据，全程无需编写代码。

**内置卡片：开箱即用。**
系统内置覆盖三个阶段的常用卡片：信息提取（设备列表、当前界面、截图、读取全局变量）、逻辑分析（打印、图像匹配、OCR 识别、字符串与数值比较、自定义代码）、执行操作（点击、滑动、亮屏/息屏、开机/关机、解锁、返回、启动与停止应用、延时等待等）。

**自定义卡片：按需扩展。**
当内置卡片无法满足需求时，可在项目目录中创建 `custom_task.py`，以与内置卡片相同的声明方式定义新卡片；前端启动时自动识别并纳入卡片面板，无需修改任何源码。

## 主要功能

- 🎨 **可视化流程编排** —— 通过拖拽与连线搭建自动化流程，所见即所得
- 🔌 **自动生成脚本** —— 流程构建完成后自动生成并导出可读、可执行的 Python 脚本，无需手写代码
- ↩️ **撤销与重做** —— 支持操作回退，编辑更加从容
- 📋 **模块复用** —— 支持复制粘贴，常用模块可跨项目复用
- 🌙 **个性化界面** —— 支持暗黑模式与中英文双语切换
- 💾 **本地持久化** —— 项目自动保存至本地，无需担心数据丢失
- 📱 **扩展能力** —— 接入后端服务后，支持真机设备控制、定时任务调度与运行历史查看

## 快速开始

运行环境要求：**Node.js**（建议 v18 及以上）。

```bash
npm install      # 安装依赖（仅需一次）
npm run dev      # 启动开发服务
```

启动后，在浏览器中打开终端显示的地址（通常为 `http://localhost:5173`），选择一个文件夹作为工作目录即可开始使用。

> 若希望免去命令行操作，可等待官方发布的**已打包版本**（包含后端服务），开箱即用。

## 技术栈

| 用途 | 技术 |
| --- | --- |
| 界面 | 原生 JavaScript + Vite（无框架） |
| 画布 | HTML / CSS / SVG |
| 脚本生成与运行 | Python（浏览器内 Pyodide + 自带 DSL 运行时） |
| 数据存储 | 浏览器本地（File System Access + IndexedDB） |
| 与后端通信 | WebSocket |

---

## 开源与后端

本仓库为**开源前端**，可免费使用、学习与改进。流程的实际执行（在手机设备上运行）需接入后端服务——手机设备控制、任务定时调度、运行记录等高级能力由**独立的 DroidTaskFlow 后端服务**提供（另行分发），用户可按需选配。
