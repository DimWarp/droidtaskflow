6 点（degree-5）· 端点可拖拽 · 滑块实时调参

曲线公式

mx = max(abs(tx - fx) * factorx, min * zoom)
my = (ty - fy) * factory
P0 (fx, fy)
P1 (fx + mx, fy)
P2 (fx + mx, fy + my)
P3 (tx - mx, ty - my)
P4 (tx - mx, ty)
P5 (tx, ty)
公式框支持 Python 语法 → 点「应用」生效。变量 fx fy tx ty factorx factory min max zoom mx my + 自定义变量；支持 + - * / // % **、比较 < <= > >= == !=、and/or/not、三元 a if c else b、函数 abs() min() max() float('inf')。未知名自动变成可调的自定义变量。「恢复默认」还原。
